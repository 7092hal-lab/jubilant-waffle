## 단계와 예상 규모

1. 계획·기록(이 단계): REQUEST/PROGRESS/LOG 작성, 푸시.
2. 초안 작성: 주 에이전트가 최고 설정으로 직접 작성. 예상 30~36k자(90~110KB).
3. 초안 업로드: 파일 카드 전송 + Claude Doc 게시. 검토 시작 전.
4. 다중 검토(병렬, 작성에 관여하지 않은 새 에이전트 3): (a) 행동 스모크 테스트(초안을 지침으로 10개 안팎 시나리오 실행·판정), (b) 독립 검토(사양서 대조표·모순·정직 경계·안전·저본 규칙 보존), (c) 한국어 문체·지침 효과 검토.
5. 수정 + 고친 부분만 재검토 1회.
6. 마감 통독(새 에이전트 1): 용어·참조·중복·늘어진 문장 정리, 내용 삭제 없음. 편집 목록을 받아 주 에이전트가 적용.
7. 제출 전 대조, 기록 갱신, 커밋·푸시, 최종 파일 전송, 인계 메모.

예상: 대화 1개(이 세션), 보조 에이전트 4(검토 3 + 통독 1), 검토 1회 + 고친 부분 재검토 1회.

## 결정

- D1 (2026-10-19): 계획 확인을 기다리지 않고 초안으로 넘어간다. 근거: SJ가 '계획 → 초안 → 업로드' 순서를 명시했고 세션이 무인. 영향: SJ가 계획을 바꾸면 그 시점에 반영.
- D2: '문서 형태로 업로드' = 세션 파일 카드 전송 + Claude Doc 전문 게시. 근거: 저본이 .txt이고 Doc 연결이 있음.
- D3: 관계 한계(연인 틀 금지)와 자해·자살 대응은 저본 그대로. 근거: 고정 한계이고 의뢰에 변경 요청 없음.
- D4: 사용자 정보 칸에 선택 항목 '자리'(기본 없음)를 추가한다. 근거: 지어내지 않고 Lyra의 현존감을 올리는 손잡이. 영향: SJ가 원치 않으면 지워도 본문이 깨지지 않게 쓴다.
- D5: 저본의 본문은 되도록 그대로 두고, 빠진 사양 항목을 더하고 장면·몸·앎을 확장한다. 근거: 저본은 검증된 글이라 전면 재작성은 퇴행 위험.
